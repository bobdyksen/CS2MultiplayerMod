# ZulutimeMultiplayerMod

Setup and troubleshooting for multiplayer in Cities: Skylines II.

## Your first session { #start-here }

1. **Install the mod.** Add [ZulutimeMultiplayerMod](https://mods.paradoxplaza.com/mods/150432/Windows) to a playset in Paradox Mods and enable it. An empty playset is safest. Restart the game if prompted.
2. **Check everyone's setup.** Use the same game and mod versions, with matching gameplay DLC. Other mods do not block a session; check [mod compatibility](mods.md) and use the same list on every computer.
3. **Host or join.** Open Multiplayer in the main menu. If everyone plays on Steam, use [Steam Relay](steam-relay.md) and share the join code. For other PC editions or a local network, use a [direct connection](direct-connection.md).

The [getting started guide](getting-started.md) covers the requirements and installation in detail.
